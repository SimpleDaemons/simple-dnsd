simple-dnsd - Read Me

Quick Start

After installation, simple-dnsd will be available as a system service.

Configuration

Edit the configuration file:

/etc/simple-dnsd/simple-dnsd.conf

Service Management

Start the service:

sudo systemctl start simple-dnsd

Enable at boot:

sudo systemctl enable simple-dnsd

Full documentation is available at:
